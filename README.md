# Forex Trading AI — Electron Wrapper

Wraps the Flask dashboard in a desktop window with a system tray icon.

## Prerequisites

- Node.js 18+
- Python 3.9+ (with all bot dependencies installed)

## Dev mode

```bash
cd electron
npm install
npm start
```

The app will:
1. Spawn `python src/dashboard.py` from the project root
2. Wait up to 30 s for Flask to be ready on port 5000
3. Open a 1200×800 browser window pointing at the dashboard
4. Add a system tray icon with Start/Stop/Quit controls

Closing the window **hides it to the tray** — use tray → Quit to exit fully.

## Build Windows installer

```bash
cd electron
npm run build
```

Produces `dist/Forex Trading AI Setup 1.0.0.exe` (NSIS installer).

## Icon

`assets/icon.png` is a placeholder generated by `generate_icon.js`.
Replace it with a proper 256×256 PNG before a release build.
`assets/icon.ico` must be a real ICO file for the NSIS installer icon.

## Project structure

```
electron/
  main.js          — Electron main process
  preload.js       — empty preload (contextIsolation: true)
  package.json     — npm config + electron-builder config
  generate_icon.js — one-shot icon generator (dev utility)
  assets/
    icon.png       — 256×256 app icon (placeholder)
    icon.ico       — ICO copy (placeholder; convert for release)
  README.md
```
